<h2>🎓 AttendX — Smart Classroom Attendance Management System</h2>

AttendX is an AI-powered, proxy-resistant classroom attendance management system developed collaboratively by Team Hunters for the SIH 2026 Internal Hackathon.

It combines student, teacher, class, and schedule management with live attendance monitoring and periodic identity verification.

<h3>Key Features</h3>

Face detection and recognition using YuNet and SFace

Three periodic verification rounds during a class session

Student, teacher, class, and schedule management

Live attendance monitoring and automated attendance status

React + TypeScript frontend

Python Flask backend with an SQL database
